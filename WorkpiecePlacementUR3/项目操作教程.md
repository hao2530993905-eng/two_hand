# WorkpiecePlacementUR3 项目操作教程

这是一份面向现场操作者的使用手册。建议第一次使用时严格按照本文顺序执行，不要跳过干运行、坐标检查和低速测试。

```text
机械臂 IP：192.168.1.4
相机：RealSense D455
相机序列号：105322250617
夹爪端口：63352
项目目录：/home/sjh/WorkpiecePlacementUR3
```

## 一、最重要的四套完整流程

项目目前有四套主要使用流程：

1. `continuous_visual_pick_and_place.py`：连续识别和抓取白色工件，依次放入红色工件中未使用的目标位，最多连续放置 4 个。
2. `visual_pick_and_place.py`：白色工件视觉抓取、红色工件识别、最近凹槽计算和投放的单次全流程。
3. `detect_and_pick.py`：用相机和 YOLO 检测单个工件，然后移动到工件表面正上方指定高度。
4. `pick_and_place.py`：使用事先确定的抓取和放置位姿，执行下降、夹取、搬运和释放。

## 0. 白色抓取并投放到红色凹槽的全流程

完整入口：

```text
complete_process/visual_pick_and_place.py
```

流程：

```text
随机识别一个白色工件
→ 以白色 OBB 长边中更靠近 base_link 原点的一端为起点，取长边 9/16 位置作为抓取点
→ 夹爪两指连线对齐白色 OBB 短边
→ moveJ 到白色工件表面上方 10 cm
→ moveL 下降 6 cm
→ 闭合夹爪
→ 从抓取点直接 moveL 向上移动 15 cm
→ 切换 red_box.pt
→ 识别红色放置板
→ 以 base_link X 较小的短边端点为起点，在短边 11/32、21/32 处；长边从远离 base_link 原点的一端取 9/16，计算两个槽中心
→ 选择离当前 TCP 最近的槽
→ 夹爪两指连线对齐红色 OBB 短边
→ moveJ 到槽中心上方 20 cm
→ moveL 下降 8 cm
→ 在槽表面上方 12 cm 处打开夹爪投放
```

姿态参考值来自现场测量：夹爪垂直向下、两指连线平行 UR Base X 时：

```text
[2.204603, -2.213467, -0.020398]
```

该基准姿态下的六个关节角约为
`[90°, -90°, 90°, 270°, -90°, 270°]`（关节角按 360° 等价）。

程序只绕 UR Base Z 调整抓取方向，并自动选择相差 180° 的两个等价姿态中离当前姿态更近的一个。

## 2. 使用固定点位完成抓取和放置

`pick_and_place.py` 适用于抓取点和放置点已经通过示教或测量确定的情况。

位姿格式：

```text
[x, y, z, rx, ry, rz]
```

位置单位为米，旋转向量单位为弧度。

先读取当前 TCP 位姿，记录安全的抓取接近点和放置接近点：

```bash
cd /home/sjh/WorkpiecePlacementUR3
/home/sjh/anaconda3/envs/lerobot_eye_cuda114_clone/bin/python \
  workpiece_demo/read_current_pose.py --host 192.168.1.4
```

完整抓放命令模板：

```bash
cd /home/sjh/WorkpiecePlacementUR3
/home/sjh/anaconda3/envs/lerobot_eye_cuda114_clone/bin/python \
  complete_process/pick_and_place.py \
  --host 192.168.1.4 \
  --pick-pose PICK_X PICK_Y PICK_Z PICK_RX PICK_RY PICK_RZ \
  --pick-distance -0.01 \
  --place-pose PLACE_X PLACE_Y PLACE_Z PLACE_RX PLACE_RY PLACE_RZ \
  --place-distance -0.01 \
  --joint-speed 0.10 \
  --joint-acc 0.20 \
  --speed 0.01 \
  --linear-acc 0.05 \
  --gripper-speed 100 \
  --gripper-force 100 \
  --retreat-after-place
```

执行顺序：

```text
打开夹爪
→ moveJ/IK 到抓取接近位姿
→ moveL 下降 pick-distance
→ 关闭夹爪
→ moveL 返回抓取接近位姿
→ moveJ/IK 到放置接近位姿
→ moveL 下降 place-distance
→ 打开夹爪
→ 可选返回放置接近位姿
```

`pick-distance` 和 `place-distance` 是 UR 控制器基坐标 Z 方向的有符号距离：

```text
负数：下降
正数：上升
```

第一次测试建议从 `-0.005` 即 5 mm 开始，不要直接使用较大的下降距离。

## 9. 使用深度差分识别工件

先启动 D455，然后：


程序同时要求：

```text
目标相对空工作台有足够高度
目标颜色满足设置
轮廓面积不小于 min_area
```

颜色可选：

```text

```

清空工作区，点击 `Depth detection` 窗口后按 `B`，采集新的空背景。相机或工作台移动后必须重新采集。

快捷键：

| 按键 | 操作 |
| --- | --- |
| `B` | 采集空背景 |
| `R` | 恢复全图 ROI |

import cv2
import numpy as np

from complete_process.utils.base.ur_base import UR_BASE

HOST = "192.168.1.4"
DISTANCE_M = 0.05   # TCP +Z 方向10 mm；负数为 TCP -Z
SPEED = 0.02
ACC = 0.03
TIMEOUT = 30.0

if abs(DISTANCE_M) > 0.05:
    raise ValueError("单次测试距离不得超过50 mm")

with UR_BASE(HOST) as robot:
    start = np.asarray(
        robot.get_tcp_pose_or_raise(),
        dtype=np.float64,
    )

    rotation, _ = cv2.Rodrigues(start[3:])

    target = start.copy()
    target[:3] += rotation[:, 2] * DISTANCE_M

    print("当前位姿:", start.tolist())
    print("TCP +Z方向:", rotation[:, 2].tolist())
    print("目标位姿:", target.tolist())
    print("移动距离:", DISTANCE_M * 1000.0, "mm")

    print("确认安全后输入 MOVE：", end="", flush=True)
    with open("/dev/tty", "r", encoding="utf-8") as terminal:
        confirmation = terminal.readline().strip()

    if confirmation != "MOVE":
        raise SystemExit("已取消，没有移动")

    result = robot.move_l(
        target.tolist(),
        SPEED,
        ACC,
        TIMEOUT,
    )
    print(result)

    if not result.success:
        raise RuntimeError(result.message)
