# UR3 双机械臂与工件放置项目

本仓库汇总三个可独立使用的项目：

- `two_hand/`：双机械臂抓取与放置流程。
- `second_hand/`：第二机械臂、相机标定和白色矩形抓取流程。
- `WorkpiecePlacementUR3/`：UR3 工件识别、抓取与连续放置流程。

各项目的安装、标定和启动方式请查看对应目录内的 README 与中文操作指南。

仓库保留了运行所需源码、配置、ROS 包、机器人资源和推理模型；编译产物、缓存、调试图片、训练数据、训练输出及标定归档由根目录 `.gitignore` 排除。克隆后需要按各项目说明重新构建 catkin 工作空间。
